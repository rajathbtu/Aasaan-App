# Aasaanly Name & OTP Verification — Handoff

Open `index.html` in a browser to preview the responsive screen.

## Files
- `assets/reference-approved-screen.png`: exact approved full-screen visual reference.
- `assets/illustrations/name-verification-illustration.png`: extracted illustration used in the preview.
- `assets/icons/*.svg`: reusable outline vector icons.
- `css/styles.css`, `js/app.js`: responsive HTML preview and demo interactions.
- `initial-state.html`, `filled-state.html`, `verified-state-reference.html`: state examples.
- `NAME_OTP_UI_UX_SPEC.md`: design, behavior and implementation specification.
- `VS_Code_Agent_Prompt.txt`: ready-to-paste implementation prompt.
- `ASSET_MANIFEST.json`: asset inventory.

The phone number and OTP countdown in the preview are illustrative placeholders. Production must bind them to existing app/auth state and APIs.
